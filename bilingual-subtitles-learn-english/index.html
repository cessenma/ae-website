手機、平板、電視可以開雙語字幕嗎？

手機和平板：Netflix 和 Disney+ 通常是用 App 看，App 一次只能選一種字幕，也不能加裝工具，所以開不了雙語字幕。YouTube 多一條路：不用 App，改用瀏覽器開 youtube.com。iPhone 和 iPad 用 Safari，從 App Store 安裝 Trancy 或沉浸式翻譯的 Safari 擴充功能；Android 用 Firefox 或 Edge 加裝同樣的工具。螢幕小，兩行字會擋住不少畫面。

YouTube App 的「自動翻譯」：在字幕設定裡可以把字幕換成中文，但還是一次一行，而且是機器翻譯。它適合用來「先看懂」，不是雙語字幕。

電視：電視上的 App 只能選一種字幕，電視也不能裝擴充功能。全家想在大螢幕一起看雙語字幕，做法是先在電腦的瀏覽器開好，再用 HDMI 線把電腦接到電視，這時候電視只是電腦的螢幕。

雙語字幕能學英文嗎？4 份研究怎麼說

有幫助，但幫的是「看懂」和「記住字義」；要記住英文字本身，還是得看英文那一行。下面 4 份都是發表在學術期刊的研究。前兩份的對象是成人，而且四份都只看一次影片，所以只能當參考，不能直接套在每個孩子身上。

四份放在一起看：有字幕比沒有字幕好；雙語字幕幫助理解，沒有增加負擔；但看雙語字幕時，看中文翻譯的時間比看英文生字多，而學到多少英文，只和看英文字的時間有關。

用字幕學英文 4 步驟：同一集看四遍

字幕是工具，學不學得到看怎麼用。最簡單的做法是同一集看四遍，每一遍換一種字幕。選一集 10 到 20 分鐘、孩子本來就喜歡的影片；四遍不用同一天看完，分四天也可以。

還不太會讀英文的孩子，字幕幫不上忙，重點放在聽和看畫面就好。第二張表是依孩子的閱讀程度選字幕的建議。

字幕的英文怎麼說：subtitles、CC、SDH 差在哪

字幕的英文是 subtitles。選單上常見的 CC 是 closed captions：Netflix 的說明是，subtitles 是把對白變成畫面上的文字，closed captions 除了對白，還會描述聲音。雙語字幕可以說 dual subtitles 或 bilingual subtitles。

雙語字幕常見問題

Netflix 的官方說明只有選一種字幕語言的做法，沒有同時顯示兩種語言的設定（2026-11-18 查閱）。要看中英兩行，得用電腦的瀏覽器開 netflix.com，並加裝 Language Reactor、Trancy 或沉浸式翻譯這類擴充功能。手機、平板和電視上的 Netflix App 不能加裝工具。

電腦：用瀏覽器開 youtube.com，加裝雙語字幕的擴充功能。手機：YouTube App 一次只顯示一種字幕，要兩行得改用瀏覽器開 youtube.com，iPhone 和 iPad 用 Safari 加 Safari 擴充功能，Android 用 Firefox 或 Edge。App 裡的「自動翻譯」只是把字幕換成另一種語言，不是雙語字幕。

雙語字幕是 Language Reactor 的免費功能；Pro 版另外收費，多了機器翻譯、存單字等功能。它的官網註明只支援電腦，安裝的是 Chrome 擴充功能，沒有手機或平板版（2026-11-18 查閱）。

電視上的 Netflix、YouTube、Disney+ 都只能選一種字幕，電視也不能裝擴充功能。做法是在電腦的瀏覽器開好雙語字幕，再用 HDMI 線把電腦接到電視，把電視當成電腦的螢幕。

雙語字幕幫助看懂劇情、記住字義，但有研究發現，觀眾看中文翻譯的時間比看英文生字久，而學到多少英文只和看英文字的時間有關。建議把雙語字幕當第一遍，之後換成英文字幕，再跟著唸，最後關掉字幕只用聽。還不太會讀英文的孩子，字幕幫助有限，重點放在聽。

雙語字幕是 dual subtitles 或 bilingual subtitles。CC 是 closed captions（隱藏式字幕），除了對白還會描述聲音，例如 [music]。一般的字幕是 subtitles。

三件事：只從瀏覽器的官方商店安裝；安裝前看更新日期、使用人數和評價；孩子用的電腦，不看影片的時候可以先把擴充功能關掉。擴充功能要讀取影音網站的頁面才能加上字幕，所以選有持續更新、使用人數多的工具比較安心。
