color 還是 colour？

color 是美式，colour 是英式，兩個都正確。同一組差異還有 gray（美）／grey（英）。

台灣的審定教科書（康軒、翰林、南一）採美式拼法，多益也是美式；劍橋與全民英檢兩種都接受。我們教的是美式英語，所以本頁一律以美式拼法為主。考試不會因為你用另一套而扣分，但同一篇文章裡必須一致——這才是真正會被扣分的地方。

深淺怎麼說：light、dark 與 -ish

light + 顏色 = 淺（light blue 淺藍）；dark + 顏色 = 深（dark green 深綠）。

pale 比 light 更淡、偏無血色；bright 是鮮豔；deep 比 dark 更濃郁。

口語裡還有一個好用的字尾 -ish，表示「有點…色的」：reddish（偏紅）、greenish（帶點綠）。不確定是什麼顏色時特別好用。

顏色放在形容詞的哪個位置

英文形容詞有固定順序，顏色排在倒數第三：數量 → 評價 → 大小 → 形狀 → 年齡 → 顏色 → 來源 → 材質 → 用途 → 名詞。

所以是 a big old red wooden box，不是 a red old big wooden box。母語者不會背這個順序，但講錯會立刻聽出來。

實務上很少同時用到五個形容詞，記住「顏色永遠緊貼在材質前面」就夠應付大部分句子。

light blue。更淡可以說 pale blue，天空那種藍是 sky blue，很淺的嬰兒藍是 baby blue。深藍則是 dark blue 或 navy。

可以。Red is my favorite color（紅色是我最喜歡的顏色）裡 red 就是名詞。當形容詞時放在名詞前：a red car。

算，gold 和 silver 既是金屬也是顏色。它們同時可以當名詞和形容詞：a gold medal、painted silver。

學齡前就可以，顏色是最容易「指著實物說」的一類字。建議直接在生活裡教——穿衣服、吃水果、玩積木時順口問一句，比看字卡有效得多。

-ish 表示「大約、有點」，用在不確定或介於兩色之間時：reddish 偏紅、yellowish 偏黃。這個字尾也能用在其他形容詞上，像 tallish（有點高）。

單字背起來了，用得出來嗎？

顏色、水果、動物這些字，孩子背得起來卻用不出來，原因通常是從沒在句子裡講過。我們的課堂用實物和遊戲練，說出口的頻率比看字卡高得多。
