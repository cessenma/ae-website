英文地址怎麼寫？從小到大、一個逗號一個單位

中文地址從大寫到小：市、區、路、段、號、樓。英文剛好相反，先寫樓和號，最後才寫市和國家。每個單位之間用逗號加一個空格隔開；郵遞區號寫在市或縣的後面；最後一行是 Taiwan (R.O.C.)。寫信封時可以分成三行（信封格式另見英文書信格式）：第一行樓、號、弄、巷、段、路，第二行區、市、郵遞區號，第三行 Taiwan (R.O.C.)；填網路表格時就寫成一行。

現在全國的路牌、郵局英譯和政府文件都用漢語拼音（板橋 Banqiao、新莊 Xinzhuang）。2008 年以前的通用拼音（Sinjhuang）和更早的威妥瑪拼音（Panchiao）還會出現在舊文件和舊招牌上，但寫地址時一律用漢語拼音，郵局的查詢系統給的也是這一套。

3 碼（220）和 3+3 碼（220001）都收得到；3+3 碼分得更細，郵局可以更快分揀。位置固定寫在市或縣的名字後面：Banqiao Dist., New Taipei City 220。填國外表格時放在 ZIP / Postal code 那一格。

可以。很多國家的郵政系統建議信封上的地址全部大寫，比較好辨認：1F., NO. 4, LN. 89, ZHONGZHENG RD., BANQIAO DIST., NEW TAIPEI CITY 220, TAIWAN (R.O.C.)。填表格時用一般的大小寫就好。

照選就好，這是國際標準 ISO 3166 的名稱寫法，影響的只是選單文字，包裹和信件都會正常寄到台灣。地址其他欄位照本頁的格式填，最後把郵遞區號填對最重要。

現在是 Banqiao。Panchiao 是威妥瑪拼音的舊寫法，板橋車站的舊英文名和老店的招牌還看得到。寫地址、報名、寄件一律用 Banqiao，郵局和捷運用的都是這個。
