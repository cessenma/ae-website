台灣水果的英文，為什麼常常查不到

因為很多熱帶水果在英語系國家不常見，名稱沒有完全統一。幾個實用提醒：

蓮霧最通行的說法是 wax apple，也有人說 rose apple 或 java apple。
釋迦是 sugar apple 或 custard apple（嚴格說是不同品種，但日常混用）。
芭樂是 guava，重音在第一音節：GUA-va。
楊桃是 star fruit，因為橫切面是星形——這個字孩子一聽就記住。

遇到真的沒有對應字的水果，母語者的做法是描述它：It's a bit like a pear, but crunchier. 這比硬記一個沒人用的譯名實用得多。

水果是可數還是不可數

一顆一顆算的水果是可數的：an apple、two bananas、three oranges。

切開或當成食材時變不可數：Would you like some watermelon?（來點西瓜嗎）——這裡不會說 a watermelon，因為指的是切好的果肉。

a 還是 an 看發音，不是看字母：an apple、an orange（母音開頭）；a banana、a pear（子音開頭）。注意 an avocado 是 an，但 a uniform 卻是 a——因為 uniform 的開頭唸 /j/，是子音。

水果英文常見問題

guava，重音在第一音節。這個字在英語系國家通用，果汁和果醬上都看得到，直接說就懂。

最通行的是 wax apple（字面「蠟蘋果」，因為表皮光亮）。也有人說 rose apple 或 java apple，三種在英語系國家都有人用。

sugar apple 或 custard apple。嚴格說兩者是不同品種，但日常對話裡混用不會造成誤解。台東鳳梨釋迦則常譯為 atemoya。

看開頭的發音：母音開頭用 an（an apple、an orange、an avocado），子音開頭用 a（a banana、a guava）。判斷依據是聲音不是字母。

a bunch of bananas。其他常用單位：a bunch of grapes（一串葡萄）、a slice of watermelon（一片西瓜）、a basket of strawberries（一籃草莓）。

去一趟市場或超市，邊走邊說。水果是最適合實物教學的一類字——看得到、摸得到、吃得到，記憶點比字卡強太多。回家再用那幾個字造一句就夠了。
