英文不規則動詞完整列表
分類記憶法與常錯排行

作者：Christopher｜埃森美語創辦人｜美國密西根大學畢業、美國正式教師執照

找「不規則動詞表」的人，多半手上已經有一張——按字母順序 A 到 Z 排、一百多個動詞、背了忘、忘了背的那種。問題不在孩子不用功，在字母順序是給查閱用的，不是給記憶用的：begin 和 bring 排在一起，變化方式卻完全不同，大腦找不到規律，只能硬記。

這一頁把最常用的 74 個不規則動詞重新照「變化類型」分成四組：AAA 三態同形、ABA 首尾同形、ABB 過去式＝過去分詞、ABC 三態全變。每個動詞附上原形、過去式、過去分詞和中文意思。同一組裡的動詞變化方式相同，背一個等於背一串——這是美國老師教母語孩子時實際使用的分組，也是我在課堂上教的方式。收藏這一頁，之後隨時回來查。

先懂原理

為什麼分類記憶比字母順序死背有效？

因為大腦天生是找規律的機器。最好的證據來自美國孩子自己：幾乎每個英語母語的小孩，在兩到四歲之間都會說出 goed、eated、runned 這種「錯誤」——他們沒有從大人那裡聽過這些字，是自己歸納出「過去式加 -ed」的規則後，套用到所有動詞上。語言學家把這叫做「過度規則化」（overregularization），它是語言發展的正常階段，也證明了一件事：孩子學動詞變化，靠的是抓規律，不是背清單。

不規則動詞其實也不是真的「無規則」——它們是古英語靠改變母音表達過去的遺跡，所以內部藏著好幾套小規律：sing–sang–sung 和 drink–drank–drunk 是同一個模式，buy–bought 和 teach–taught 是同一個模式。照類型分組，就是把這些隱藏的規律攤開來給孩子看：記憶單位從「74 個動詞」變成「四大類、幾個小家族」，負擔立刻少一半以上。下面就是完整的分組列表。

第一組 · 最好背

AAA 型：三態同形（11 個）

原形、過去式、過去分詞完全一樣——這組先背，馬上有成就感。共同特徵：多半是短短的、以 t 或 d 結尾的單音節動詞。

  • cut → cut → cut｜切、剪
  • put → put → put｜放
  • cost → cost → cost｜花費（金錢）
  • hit → hit → hit｜打、撞
  • let → let → let｜讓
  • set → set → set｜設定、放置
  • shut → shut → shut｜關上
  • hurt → hurt → hurt｜使受傷、疼痛
  • quit → quit → quit｜停止、辭去
  • spread → spread → spread｜散播、塗抹
  • read → read → read｜閱讀 ⚠️ 拼法同形，但過去式與過去分詞發音變成 /rɛd/（同 red）——聽力與口說最愛考

陷阱提醒：三態同形不代表「不用變」——句子裡還是要判斷時態。He cut the paper yesterday. 的 cut 是過去式，只是長得跟原形一樣。

第二組 · 最小巧

ABA 型：首尾同形（3 個）

原形和過去分詞相同、只有過去式不一樣的迷你家族——整個英文常用動詞裡就這三個，一次記完：

  • come → came → come｜來
  • become → became → become｜變成、成為
  • run → ran → run｜跑

become 就是 be + come，跟著 come 一起變——很多長動詞都是這樣「跟著短動詞走」的（understand 跟 stand、forget 跟 get），發現這件事又能省下好幾個記憶格。

第三組 · 最大宗

ABB 型：過去式＝過去分詞（32 個）

過去式和過去分詞相同——常用動詞裡最大的一組，但內部又分成幾個「小家族」，家族內的變化一模一樣：

-ought／-aught 家族（發音全部一樣）

  • buy → bought → bought｜買
  • bring → brought → brought｜帶來
  • think → thought → thought｜想、認為
  • fight → fought → fought｜打架、奮戰
  • catch → caught → caught｜抓住、趕上
  • teach → taught → taught｜教

-ept／-elt／短母音＋t 家族（字尾收 t）

  • feel → felt → felt｜感覺
  • keep → kept → kept｜保持、保存
  • sleep → slept → slept｜睡覺
  • sweep → swept → swept｜掃
  • meet → met → met｜遇見、認識
  • leave → left → left｜離開、留下
  • lend → lent → lent｜借出
  • send → sent → sent｜寄、送
  • spend → spent → spent｜花（時間、金錢）
  • build → built → built｜建造
  • lose → lost → lost｜遺失、輸

say–said 小家族（拼法收 -aid／-ade／-eard）

  • say → said → said｜說 ⚠️ said 唸 /sɛd/，不是「say-d」
  • pay → paid → paid｜付錢
  • make → made → made｜做、製作
  • hear → heard → heard｜聽見

母音大搬家家族（多半變成 o 或其他母音）

  • tell → told → told｜告訴
  • sell → sold → sold｜賣
  • find → found → found｜找到
  • win → won → won｜贏
  • sit → sat → sat｜坐
  • stand → stood → stood｜站
  • understand → understood → understood｜了解（跟著 stand 變）
  • hold → held → held｜握、舉行
  • have → had → had｜有
  • get → got → got｜得到 ⚠️ 美式過去分詞常用 gotten（have gotten）
  • feed → fed → fed｜餵
第四組 · 最常考

ABC 型：三態全變（28 個）

三個形態都不一樣——看似最難，其實小家族最整齊，考試也最愛從這組出題：

i–a–u 家族（母音照 i→a→u 換，超好記）

  • begin → began → begun｜開始
  • drink → drank → drunk｜喝
  • sing → sang → sung｜唱歌
  • swim → swam → swum｜游泳
  • ring → rang → rung｜（鈴）響

過去分詞 -en／-n 家族（分詞長出 n 的尾巴）

  • take → took → taken｜拿、帶
  • write → wrote → written｜寫 ⚠️ written 要雙 t
  • drive → drove → driven｜開車
  • ride → rode → ridden｜騎 ⚠️ ridden 要雙 d
  • eat → ate → eaten｜吃
  • give → gave → given｜給
  • speak → spoke → spoken｜說（語言）
  • break → broke → broken｜打破
  • steal → stole → stolen｜偷
  • choose → chose → chosen｜選擇
  • wake → woke → woken｜醒來
  • forget → forgot → forgotten｜忘記（跟著 get 變）
  • wear → wore → worn｜穿、戴
  • fall → fell → fallen｜落下、跌倒

-ew／-own 家族（過去式 -ew、分詞 -own）

  • know → knew → known｜知道、認識
  • grow → grew → grown｜成長、種植
  • throw → threw → thrown｜丟
  • fly → flew → flown｜飛
  • draw → drew → drawn｜畫

完全不按牌理家族（最高頻，只能各個擊破——但天天用得到，很快就熟）

  • go → went → gone｜去（went 原本是另一個動詞 wend 的過去式，被 go「借」來用——難怪長得完全不像）
  • see → saw → seen｜看見
  • do → did → done｜做
  • be（am／is／are）→ was／were → been｜是、在
背法實戰

三個比抄寫十遍有效的練習方法

方法 1：放進句子裡用，不要孤立地背

「go-went-gone、go-went-gone」唸一百次，考試時還是可能寫錯，因為大腦沒有把它跟「意思」掛勾。每學一個動詞，立刻造一個關於自己的句子：I went to Taipei last Sunday.／I have never eaten snails. 有畫面、有情感的句子，記憶留存率完全不同。

方法 2：用過去式說故事

把今天發生的事、看過的故事，用英文過去式重講一遍——這是美國小學課堂天天在做的 retelling。講故事時動詞會自然大量出現（woke up、ate、went、saw、came home），孩子是在「使用中」固定動詞變化，而不是在背清單。程度還不夠自己說的孩子，家長可以帶著接龍：你說一句、孩子接一句。

方法 3：每日快問 5 個（quick daily 5）

每天挑 5 個動詞口頭快問快答：「eat？」「ate, eaten！」全程不用紙筆、不用三分鐘，重點是天天做。答錯的動詞隔天再進名單，答對三天的就畢業。比起考前一晚狂背 74 個，每天 5 個的間隔複習（spaced repetition）才是記憶科學站得住腳的做法。如果孩子連原形動詞的意思都還不熟，那問題在更基礎的字彙量，建議先看〈小學英文程度落後怎麼辦〉照順序補。

段考陷阱

國中段考常錯排行：這五題年年有人中招

第 1 名：didn't ＋ 過去式（❌ didn't went）

否定句和疑問句裡，did 已經標記了過去，後面動詞要回到原形：He didn't go to school.（不是 didn't went）／Did you see it?（不是 Did you saw）。出題老師特別愛挑不規則動詞來考這一條，因為死背動詞表的學生會反射性地把動詞變過去式。

第 2 名：完成式誤用過去式（❌ has went）

have／has 後面要接過去分詞：She has gone home.（不是 has went）。ABB 型動詞因為過去式＝過去分詞而感覺不到差別，一遇到 ABC 型（go／see／take）就現形——這正是三態要一起背的原因。

第 3 名：把不規則動詞規則化（❌ cutted、putted、teached）

跟美國小孩說 goed 是同一個現象：規則學會了，例外還沒固定。寫錯不用罵，這其實是「規則有學進去」的證據，靠使用量修正即可。

第 4 名：read 的發音

拼法三態同形，發音卻會變：過去式／過去分詞唸 /rɛd/。聽力題播 I read it last night. 時，唸的是「red」——沒練過發音、只背過拼法的學生就會漏聽時態。

第 5 名：三態順序背混（過去式、過去分詞張冠李戴）

❌ I have saw that movie.／❌ He seen it yesterday. 補救方式不是重背，而是回到句子：have 後面只能接分詞、單獨當動詞只能用過去式——用「句型帶動詞」練，比默寫表格有效。

觀念總結

動詞變化是習得出來的，不是背出來的

回到開頭那個畫面：美國三歲小孩說 I goed there，沒有人給他動詞表，也沒有人罰他抄寫——他靠著每天大量地聽和說，先歸納出規則，再一個一個把例外「用」到正確。到了小學，老師才用分類和拼字規則把它整理成系統。順序是：先使用，再整理；台灣常見的做法剛好相反，先發一張字母順序的表叫孩子背，孩子沒有使用量，只能靠短期記憶應付小考，考完就還給老師。

這份分類表能幫孩子把記憶量減半，但真正讓動詞變化「長進直覺」的，是每天開口用英文說過去的事。這也是我們的常規全美語小班課每天在做的事——不是動詞表小考，而是讓孩子在真實對話和故事重述裡，把 went、saw、ate 用到不會錯。

常見問題

不規則動詞常見問題

要，但不用全背。英文的不規則動詞總數有一百多個，其中真正高頻的大約 70–80 個——本頁整理的 74 個涵蓋了日常對話、課本與考試絕大多數的使用場景。它們偏偏都是最常用的動詞（go、see、eat、make、take），所以躲不掉；好消息是正因為天天用得到，用對方法很快就會變成直覺。

兩個原則：分類、使用。先照變化類型分組（AAA 三態同形、ABA、ABB、ABC），讓大腦抓到規律，記憶量立刻少一半；再把每個動詞放進句子裡實際使用——造句、用過去式說昨天的事，比抄寫十遍有效得多。每天挑 5 個口頭快問快答，兩三週就能把常用動詞走完一輪。

這些動詞是古英語「強變化動詞」的遺跡——一千多年前的英語靠改變母音來表達過去（sing→sang、drink→drank），後來多數動詞改用 -ed 規則，但最常用的一批動詞因為天天被使用、形式深植人心，反而保留了古老的變化方式。所以不規則動詞幾乎都是高頻字：越常用的字，越不容易被規則化。

拼法完全一樣（read-read-read），但過去式和過去分詞的發音變成「red」（同 red 紅色）。這是聽力和口說最容易露餡的一題：I read a book yesterday. 裡的 read 必須唸 /rɛd/。段考的聽力題和口說評量都很愛考這個。

因為「過去」這件事只需要標記一次。didn't 裡的 did 已經表達過去了，後面的動詞要回到原形：didn't go。同理疑問句 Did you see it?（不是 Did you saw）。這是國中段考不規則動詞的第一大陷阱——題目故意用不規則動詞，就是要看你會不會多變一次。

過去式單獨當動詞用，描述過去發生的事（I saw him yesterday.）；過去分詞不能單獨當動詞，要跟 have／has 組成完成式（I have seen it.），或跟 be 動詞組成被動語態（The window was broken.）。國一先用到過去式，過去分詞在國二學完成式時才正式登場——但建議背的時候三態一起背，之後不用重背一次。

兩個都對，差在地區：美式英語常用 gotten（have gotten），英式用 got（have got）。台灣課本兩種都可能出現，考試時跟著課本版本寫即可。這也是為什麼本頁把 get 放在 ABB 組但特別註記——它是少數「同一個動詞、兩種變化都通行」的例子。

背了就忘，通常是因為只有「背」沒有「用」。我們的常規全美語小班課（每班 12 人以內、美籍持證教師）讓孩子天天在真實對話裡使用過去式——說昨天做了什麼、重述故事——動詞變化是在使用中自然固定下來的，就像美國孩子習得的方式。想知道孩子目前的動詞基礎在哪個階段，歡迎加 LINE 預約免費程度評估，也可以留言「動詞表」索取本頁的列印版。
