官方題型說明 Task format

六個空格，每格自己寫一個字、沒有選項。考文法功能詞——介系詞、冠詞、助動詞、關係代名詞這一類。拼錯就是錯。官方考卷中為 第 27–32 題。

題目說明（rubric）依照官方題型格式以英文呈現；以下練習題為埃森美語原創編寫，用於熟悉題型，非劍橋官方試題。官方免費樣卷：cambridgeenglish.org → B1 Preliminary for Schools preparation。

For each question, write the correct answer. Write ONE word for each gap.
